# MoeSOC Endpoint 1.0.0 — release notes (draft, not published)

MoeSOC Endpoint is a local-first Windows host detection and investigation tool. It reads
the Security log and, when present, Sysmon, PowerShell and Microsoft Defender logs,
runs twelve explainable rules and correlations, and helps an analyst triage, investigate
and report — without sending any data anywhere and without changing the system.

**Highlights:** cross-source correlation with labelled link strength, investigation
stories, explainable risk, auditable tuning and suppressions, redacted HTML reports,
retention, and a packaged Windows executable. See [CHANGELOG.md](../../CHANGELOG.md).

**Safety by design:** read-only telemetry; no audit-policy changes; never installs
Sysmon; no blocking, killing, quarantine or other response actions; findings are leads,
not proof; Defender verdicts are attributed to Microsoft Defender.

**Requirements:** Windows 10/11 x64; administrator approval (standard UAC prompt) to
read the Security log. Optional: Sysmon, PowerShell Script Block Logging.

**Known limitations:** see the README. Notably, the executable is unsigned (SmartScreen
warning on first run), live monitoring follows the Security log only, and several
real-machine checks (Sysmon, Defender EICAR, elevated live subscription) are listed in
`docs/manual_validation_queue.md`.

**Assets (to attach when publishing):** `MoeSOC-Setup-x64.exe` (once built with Inno
Setup) or a zip of `dist\MoeSOC\`, plus `SHA256SUMS.txt`.
